# Deduplicator

Офлайн-утилита для Windows 10/11: поиск дубликатов файлов по **содержимому** (а не по имени)
и консолидация разрозненных носителей в один чистый дедуплицированный архив.

Реализовано строго по техническому заданию (`Deduplicator_TZ.md`): .NET 8, Avalonia UI (MVVM),
SQLite (WAL), многоступенчатая воронка хэширования, перцептивные хэши изображений, аудио-отпечатки,
LSH для масштаба, безопасное удаление в корзину/карантин с журналом и восстановлением.

Интерфейс полностью на русском. Без эмодзи — только векторные SVG-иконки. Эстетика в стиле Apple
(чистые поверхности, скруглённые элементы, мягкие переходы, светлая/тёмная тема). Есть собственная
иконка приложения и экран загрузки при старте.

## Возможности

| Экран | Назначение |
|---|---|
| **Носители** | Каталог подключённых и сохранённых носителей, сводка по базе, запуск сверки |
| **Проводник** | Содержимое носителя: **живой обзор диска** для подключённых (даже без сканирования), слепки из базы — для отключённых |
| **Сверка** | Выбор носителей, глубина (точные / + похожие фото / + похожая музыка), прогресс с паузой/отменой |
| **Результаты** | Точные/похожие; превью, ползунок порога, авто-выбор по правилу, экспорт CSV, «показать в папке», замена жёсткими ссылками, защита папок-эталонов |
| **Очистка** | Поиск мусора: пустые папки, файлы 0 байт, временные файлы, битые ярлыки, большие файлы — удаление в корзину |
| **Статистика** | Группы и освобождаемый объём по типам, диаграмма по категориям |
| **Здоровье дисков** | **SMART**: состояние носителя, температура, наработка, износ, ошибки чтения, прогноз отказа |
| **Консолидация** | План «уникальное → копировать, дубликаты → пропустить» и его выполнение |
| **Журнал** | История операций и восстановление из карантина |
| **Настройки** | Пороги, карантин/корзина, параллелизм, pixel-hash, правило эталона, тема, путь к fpcalc |

### Ключевые принципы (из ТЗ)
- **Сравнение по содержимому.** Переименованный/перемещённый файл опознаётся как дубликат.
- **Никогда не удалять автоматически.** Только по подтверждению, только в Корзину/карантин.
- **В группе всегда остаётся минимум одна копия** — интерфейс не даёт удалить все.
- **Похожие — только вручную.** Никаких пакетных авто-действий над «похожими».
- **Стабильность.** Битые/занятые/недоступные файлы и длинные пути не роняют процесс — пропуск с логом.
- **Возобновляемость.** Прогресс хранится в БД (WAL); сверка продолжается после прерывания.
- **Офлайн.** Ноль сетевых обращений и телеметрии.

### Защита от потери данных при сбоях (NFR-2)
- Все файловые операции записи **атомарны**: данные пишутся во временный файл, принудительно
  сбрасываются на диск (`Flush(true)`), затем атомарно переименовываются. При сбое/потере питания
  остаётся либо старый файл, либо новый — никогда «половина».
- Межтомовое перемещение — **копирование → проверка размера → удаление источника**: источник
  не удаляется, пока копия не подтверждена.
- При старте приложение удаляет «осиротевшие» временные файлы (восстановление после сбоя).
- База данных — SQLite в режиме **WAL**, запись только транзакциями.

## Архитектура

Трёхслойная структура (раздел 6 ТЗ):

```
Deduplicator.slnx
├── src/Deduplicator.Core      — ядро (engine), независимо от UI
│   ├── Models/                — доменные модели и перечисления
│   ├── Data/                  — SQLite: Database (WAL) + репозитории
│   ├── Hashing/               — XxHash128: частичный/полный хэш, побайтовая сверка
│   ├── Imaging/               — pHash, pixel-hash, миниатюры (ImageSharp + CoenM.ImageHash)
│   ├── Audio/                 — аудио-отпечатки через fpcalc (Chromaprint)
│   ├── Matching/              — LSH, MinHash, union-find, группировка, выбор эталона
│   ├── Services/              — VolumeService, ScanService, FileOpsService,
│   │                            ConsolidationService, SettingsService, StatisticsService
│   └── Util/                  — определение категории по магическим байтам, длинные пути
├── src/Deduplicator.App       — Avalonia UI (MVVM, CommunityToolkit.Mvvm)
│   ├── ViewModels/ Views/     — 8 экранов + элементы
│   ├── Converters/ Controls/  — конвертеры, SVG-иконки (PathIcon + StreamGeometry)
│   ├── Localization/Strings.cs— единый ресурсный файл строк (русский)
│   └── App.axaml              — тема (Apple-стиль), иконки, стили
└── tests/Deduplicator.Core.Tests — модульные и интеграционные тесты (xUnit)
```

### Пайплайн сканирования (многоступенчатая фильтрация, раздел 7)
1. **Обход и метаданные** — потоковый обход ФС, категория по магическим байтам, запись батчами.
2. **Группировка по размеру** — кандидаты только среди файлов одинакового размера (без чтения диска).
3. **Частичный хэш** — XxHash128 первых/последних 64 КБ (читается лишь край файла).
4. **Полный хэш** — XxHash128 целиком только для совпавших по частичному.
5. **Побайтовая сверка** — финальное подтверждение перед признанием точной копии (защита от коллизий).
6. **Перцептивный анализ** — pHash изображений и аудио-отпечатки, индексация в корзины LSH.
7. **Группировка** — точные группы + похожие (по расстоянию Хэмминга / Жаккару), с процентом схожести.

## Технологии

- **.NET 8 (C#)**, **Avalonia UI 11**, **CommunityToolkit.Mvvm**
- **SQLite** через `Microsoft.Data.Sqlite` (режим WAL)
- **XxHash128** (`System.IO.Hashing`) — быстрый хэш без нативных зависимостей
- **SixLabors.ImageSharp** + **CoenM.ImageHash** — pHash, миниатюры (управляемый код)
- **Chromaprint / fpcalc.exe** — аудио-отпечатки (единственная внешняя бинарная зависимость)

## Сборка и запуск

Требуется .NET SDK с поддержкой целевой платформы `net8.0` (среда выполнения .NET 8 должна быть установлена).

```bash
# из корня репозитория
dotnet build Deduplicator.slnx -c Release

# запуск приложения
dotnet run --project src/Deduplicator.App -c Release

# тесты
dotnet test
```

Готовый исполняемый файл: `src/Deduplicator.App/bin/Release/net8.0/Deduplicator.exe`.

### Аудио-сверка (опционально)
Похожая музыка требует `fpcalc.exe` (из пакета Chromaprint, проект AcoustID).
Скачайте сборку под Windows и положите файл рядом с приложением **или** в `tools/fpcalc.exe`
(см. `tools/README.txt`), либо укажите путь в **Настройках**. Без fpcalc остальные функции работают,
а пункт «+ Похожая музыка» становится недоступен.

## Данные приложения

Создаётся в `%LOCALAPPDATA%\Deduplicator\`:
- `deduplicator.db` — база слепков и групп (WAL);
- `Карантин\` — перемещённые файлы (восстановимы через экран «Журнал»);
- `cache\thumbnails\` — кэш миниатюр;
- `settings.json` — настройки.

Слепки хранят только метаданные и хэши (без содержимого) — порядка десятков мегабайт на миллион файлов.

## Дополнительные возможности (сверх базового ТЗ)
- **Память дисков** — отдельный экран сверки одинакового содержимого между носителями по
  сохранённым слепкам; живое отслеживание подключения/извлечения; «убрать носитель из каталога».
- **Дата создания** файлов (а не только изменения) — показывается в Проводнике.
- **Адаптивное чтение** — авто-определение HDD/SSD (WMI): на HDD/флешках чтение сериализуется,
  на SSD — параллельно (NFR-7).
- **Прогресс в процентах** на этапах хэширования и анализа фото; экран загрузки при старте.
- **Фильтры сканирования**: мин. размер файла, исключение расширений, пропуск скрытых/системных,
  автоматический пропуск системных папок (`$Recycle.Bin`, `System Volume Information` и т.п.).
- **Папки-эталоны** — файлы внутри защищены от удаления и не отмечаются авто-выбором.
- **Похожие фото с учётом поворотов/отражений** — опционально (канонический pHash по ориентациям).
- **Замена дублей жёсткими ссылками** (NTFS, один том) — освобождает место без потери данных.
- **Экспорт отчёта в CSV**, авто-выбор дублей по правилу, «показать в папке».
- **Проверка обновлений на GitHub** — по желанию (по умолчанию выключено, приложение офлайн).

## Пока не реализовано (требует внешних компонентов / вне v1)
- **Похожие/перекодированные видео** — нужен внешний `ffmpeg.exe` (как `fpcalc` для аудио);
  заложено в архитектуру, но не включено в эту сборку.
- **RAW/HEIC** превью и pHash — требует нативных декодеров (libheif и т.п.).
- Сетевые носители/NAS, мультиязычный интерфейс, облако и синхронизация — вне рамок v1 по ТЗ.
